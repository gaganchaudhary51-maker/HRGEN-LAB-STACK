# Method / Reference Range Verification

Reference intervals must not be treated as universal software constants. For every configured examination document:
- analyte/test code
- specimen
- method/analyzer
- unit
- age/sex applicability
- pregnancy or other applicable population rules
- lower/upper/reference text
- source document and effective date
- reviewer/approver

Acceptance: configured ranges match the laboratory's approved method-specific reference source. Any change requires change control and revalidation where applicable.
