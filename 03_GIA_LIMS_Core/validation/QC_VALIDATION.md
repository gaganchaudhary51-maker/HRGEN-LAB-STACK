# QC Validation

## Westgard verification set
- 1-2s: warning only
- 1-3s: reject
- 2-2s: reject
- R-4s: reject
- 4-1s: reject
- 10x: reject

For each rule, retain input points, target, SD, expected result, actual result and evidence ID.

QC approval additionally requires active instrument, active/non-expired reagent lot and PASS calibration tied to the selected instrument.
