# User Acceptance Testing (UAT)

Roles: phlebotomist, technician, pathologist, admin.

Acceptance scenarios cover registration, sample/order creation, result entry/import, QC, validation, sign-off, release, QR verification, amendment, critical communication, delta review, user disablement, backup and audit review.

UAT is accepted only by authorized laboratory representatives. Software validation does not substitute for laboratory process approval.
