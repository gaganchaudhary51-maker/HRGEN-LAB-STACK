# Release Assurance

## Security claim boundary
This project does **not** claim to be vulnerability-free. Passing automated tests, static analysis, or adversarial tests cannot prove absence of vulnerabilities.

## Production release gate
A production release requires all of:

1. Automated test suite passes.
2. Python compilation passes.
3. Independent human cross-audit is completed.
4. Production deployment rehearsal is completed successfully.
5. Release sign-off is explicitly recorded by the responsible human authority.

The `security_audit.release_gate` command fails closed unless the three external attestations are supplied as environment values:

- `human_cross_audit=true`
- `production_rehearsal=true`
- `release_signoff=true`

These attestations are **not** generated by the software itself.
