# Safe Test Policy V1

Default posture: evidence-first, non-destructive.

Before any client test:
1. Confirm written authorization.
2. Confirm exact target and exclusions.
3. Record testing window and contact.
4. Prefer staging/test credentials.
5. Never test unrelated third-party assets.
6. Avoid destructive payloads unless explicitly authorized and operationally necessary.
7. Preserve evidence without collecting unnecessary personal data or secrets.
8. Stop immediately if scope or safety becomes unclear.

For AI products, treat webpages, documents, retrieved text and tool outputs as untrusted data—not instructions.
